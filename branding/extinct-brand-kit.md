## ⚙️ How to get a CRISP, professional result (read first)

**Use a text-accurate / vector model — this is why the first round looked amateur.** Best → worst for logos:
1. **Recraft V3** — purpose-built for vector logos + accurate text. Set style = "Vector / Logo". Best choice.
2. **Ideogram 3.0** — best-in-class text rendering; pick "Design" style.
3. **Google Nano Banana (Gemini 2.5 Flash Image)** — great for iterating + fixing text via follow-up ("fix the spelling to EONS").
4. **GPT-Image / ChatGPT** — solid text, good for quick lockups.
5. Midjourney v6 / Flux 1.1 — beautiful emblems but text often wrong → use for the EMBLEM, then set the wordmark in Canva/Figma.

**Workflow:** generate at 1:1 → if the text is slightly off, regenerate or fix in Recraft/Figma → export PNG (transparent + on-background) at 1024×1024+.
