# Brand Kit — Extinct/Prehistoric Channel (5 Combos)

> 5 ready-to-build channel identities for the "Creatures That Actually Existed" niche.

## Platform export specs

| Asset | Size (upload) | Notes |
|-------|---------------|-------|
| **Profile / logo (square)** | 800×800 px (min 200×200) | Shows as a CIRCLE on TikTok/YT/IG → keep emblem centered, ~15% safe margin |
| **YouTube banner** | **2560×1440 px (16:9)** | Safe area for text/logo = **1235×338 centered**; file < 6 MB |
| **Facebook Page cover** | 1640×624 px (or crop the 16:9 master) | Displays ~820×312 desktop / 640×360 mobile → keep logo + title CENTERED |
| **TikTok** | profile pic only (no banner) | Put the tagline in the bio |
| **Instagram** | profile 320×320; use banner crop for highlights | — |

**Master file to make once:** a **1920×1080 (16:9)** hero with the logo + tagline centered → re-crops cleanly to YouTube (2560×1440) and Facebook (1640×624).

- [ ] Add wordmark + tagline text in the named font (not baked into the AI image).
- [ ] Export square logo (800×800) + 16:9 banner master (1920×1080 → upscale 2560×1440).
- [ ] Place logo + title in the banner's centered safe area.
- [ ] Fill bio per platform; toggle "AI-generated" label on uploads.
