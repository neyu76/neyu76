## ⚙️ How to get a CRISP, professional result (read first)

**Use a text-accurate / vector model** (short text + vector is the hard part):
1. **Recraft V3** — vector/logo specialist + accurate text. Style = "Vector / Logo". Best.
2. **Ideogram 3.0** — best-in-class text; style "Design".
3. **Nano Banana (Gemini 2.5 Flash Image)** — great for fixing text via follow-up ("fix spelling to EONS, keep everything else").
4. **GPT-Image / ChatGPT** — solid.
5. Midjourney/Flux render gorgeous EMBLEMS but mangle text → render the block + emblem, then set the wordmark in Figma/Canva.

**Workflow:** generate 1:1 → if a letter is wrong, regenerate or fix the wordmark in Figma with the named font → export PNG 1024×1024 (on-color block + a transparent-emblem version).

> **Why "full square block":** the colored square fills the whole frame, so the logo looks intentional and premium at every size; when platforms crop it to a circle, you still see the solid brand color with the mark centered (keep all text inside the central ~80% safe circle).
